# HTML Documentation Page

This project is a simple and clean **technical documentation webpage** built using **HTML** and **CSS**. It contains structured sections like Introduction, Getting Started, Syntax Overview, Code Examples, and Best Practices.

## 📌 Features
- Sidebar navigation  
- Clean grid layout using CSS Grid  
- Internal page links for smooth navigation  
- Responsive and easy-to-read structure  
- Beginner-friendly HTML/CSS code
